Como funciona (explicação)

Entenda o fluxo on-chain do mural BRN ⇄ USDC.

1. O que é o EscrowFactory?

É um contrato inteligente já publicado na Polygon no endereço 0x5C305aCFF5cDFAee90276c2acEA4Aa841f7062d8. Ele funciona como uma fábrica de escrows: cada vez que alguém cria uma ordem de venda, a fábrica implanta um novo contrato de escrow só para aquela ordem. Esse escrow guarda os tokens do vendedor e as regras da troca.

2. O fluxo de uma ordem

1. Vendedor aprova BRN → 2. Cria ordem (BRN travado) → 3. Comprador aprova USDC → 4. Executa a ordem → 5. Troca atômica
  1. Aprovar BRN: o vendedor autoriza a fábrica a mover seus BRN (approve no token BRN).
  2. Criar ordem: chama criarOrdem(tokenOferecido, tokenDesejado, valorOferecido, valorDesejado). A fábrica cria o escrow e puxa os BRN do vendedor para dentro dele.
  3. Aprovar USDC: o comprador autoriza o escrow a mover seus USDC.
  4. Executar: o comprador chama executar() no escrow. O contrato faz a troca atômica: manda os BRN para o comprador e os USDC para o vendedor.
  5. Cancelar: enquanto ninguém executou, o vendedor pode chamar cancelar() e receber os BRN de volta.

3. Por que é seguro?

A troca acontece dentro do contrato, na mesma transação. Ou as duas pernas (BRN e USDC) acontecem juntas, ou nada acontece. Não existe o risco de uma parte enviar e a outra não enviar — é atômico. Os BRN ficam travados no escrow, então o comprador tem a garantia de que o vendedor realmente tem os tokens.

4. O que este front-end faz

  • Lê o mural direto da blockchain (via RPC público), sem precisar de carteira.
  • Mostra o contador de ordens ativas e o estado de cada uma.
  • Faz o approve automático de BRN (para a fábrica) e de USDC (para o escrow).
  • Permite criar, executar e cancelar ordens pela MetaMask.
  • Usa vários RPCs com fallback e leitura paralela para nunca travar.
